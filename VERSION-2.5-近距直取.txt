症状
  枪口离敌人头部已经比较近时（偏差约 20~140px），自瞄转向明显变慢：
  准星到了头边开始「磨」，要 4~6 个检测周期（130~200ms）才贴上，
  而远距离一次拉枪反而利索。近 = 大框 = 贴脸，越近越钝。

根因（三层，都是「越近越减速」）
  1) 近距曲线一路降到 0px
     main.py 2026-10-26 的「远冲近稳·连续版」：偏差 < far_px(460) 起，
     ratio 按平方曲线下降，**一直降到 0px 时等于 near_ratio(0.55)**。
     于是最后几十像素每帧只肯走 55%，贴得越近越不肯动。
  2) 跟随线程的「不过目标」钳位写反了（真 bug，2026-10-28 就有）
     旧：cx = min(px,tx) if nx>tx else (max(px,tx) if nx<tx else nx)
     两个分支的 min/max 反了：步长**没**越过目标时取 max(px,tx)=tx，
     等于把航位推算的准星位置直接当成「已经到目标」→ 剩余偏差立刻变 0
     → 跟随线程每个检测周期只发出**一步**就停，预算剩下的份额全浪费。
     （这也是 10-28「一顿一顿/僵硬」的机械原因：每周期只走一步）
  3) 缩放判定用固定 10% 框高变化阈值
     贴脸时框高几百像素，准星一转框高就变 10~30% → 被判成「开镜缩放」，
     每帧重置 fov 稳定期，预算按到 fov_hold_ratio(0.3)、限幅 50px → 冻住。

改了什么（代码）
  · 新增「近距直取」贴脸带：偏差 ≤ near_boost_px(140) 时反向抬预算，
    曲线 (1-t²)²，带口处斜率 0（与 near_ratio 衔接），贴脸处 = near_boost_ratio(1.0)。
    放在 fov/开镜/过冲三道硬保护**之前** —— 真在缩放、真冲过头，那三道照样压得住。
  · 过渡带改为 [near_boost_px, far_px] 线性插值（原来按 ad/far 平方，会多压中距一脚）。
  · 跟随线程钳位改为「越过了才钳回目标」；旧行为留 `follow_clamp:false` 一键回退。
  · 过冲抑制：贴脸带用 near_damp_ratio(0.85)，带外仍是 damp_ratio(0.45)
    （原来一律 0.45，等于每次符号翻转就冻 250ms）。
  · 缩放判定阈值随框高放大：×clamp(框高/fov_change_ref_px, 1, 3)；
    fov_change_ref_px<=0 可一键关掉这个自适应。
  · 瞄准点 EMA alpha 随框高自适应（pose_smooth_big_px / pose_smooth_near）：
    贴脸时少平滑、跟得紧；远处仍 0.5 抗抖。
  · 贴脸带的绝对闸放宽到 abs_move_cap_near(0.95)，带外仍 abs_move_cap(0.85)。
